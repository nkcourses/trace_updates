Squarespace build kit

Every block below is a separate paste. Build the page top to bottom, dropping native Squarespace blocks (images, newsletter, forms, spacers) wherever you like in between.

Do the CSS once, first. Both pages share one stylesheet. Put it in Design → Custom CSS (site-wide, paste the raw CSS with no style tags) — then every markup block below just works, on any page, and you only ever edit the colours in one place.

Prefer to keep it page-local? Put it in Page Settings → Advanced → Code Injection wrapped in <style>…</style> instead.

Two things worth knowing before you start. Code blocks that run JavaScript need the Core, Plus, Advanced, Business or a Commerce plan — plain HTML and CSS work on any plan, so the pages will look right either way, but the interactive demos need one of those.

And Squarespace sometimes hides custom code while you are logged in. If a block looks empty in the editor, use Preview in Safe Mode before assuming it is broken.
